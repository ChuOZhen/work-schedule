## work schedule v0.1.0 —— 一块会自己找你的周日历

第一个可用版本。Windows 10 / 11 桌面常驻，周一开头的周视图 + 右下角苹果风玻璃提醒卡：开机、解锁、唤醒、事件开始前 10 分钟，它都会主动告诉你"接下来该干什么"。

### 下载

| 文件 | 说明 |
|---|---|
| `work-schedule-portable-0.1.0.zip` | **推荐**。解压后双击 `work schedule.exe` 即用，免安装、不写注册表 |
| Source code (zip) | 源码，`npm install && npm run dev` 即可开发 |

首次打开后建议进「设置」确认两项：**开机自动启动**（默认开）、**默认提前提醒 10 分钟**。

### 这个版本能做什么

- **周视图**：周一 → 周日 7 列 × 24 小时轴，事件按时长比例落位，重叠自动分栏，红线跟随当前时间
- **切周**：箭头 / `←` `→` / `PageUp` `PageDown` / `T` 回今天
- **事件**：点空白新建（15 分钟吸附）、点块编辑、按住拖拽改时间（跨列即改天）
- **重复**：每天 / 每周 / 每个工作日 / 每月；改单次不破坏系列（例外表存 override）
- **分类颜色**：会议 / 专注 / 事务 / 个人 / 其他 五色
- **搜索**：`Ctrl+F`，标题 + 备注模糊匹配，分「即将到来 / 过去」，点击跳转并高亮
- **提醒**：开机（`--hidden` 静默启动）、解锁、休眠唤醒、事件前 N 分钟四个来源统一收敛；45 秒节流、只显示一条、每个实例只提醒一次（持久化去重，崩溃重启不重复弹）
- **不打断**：提醒窗 `focusable:false` + `showInactive()`，全屏打字也不抢焦点；12 秒自动淡出，悬停暂停，可「稍后 10 分钟」
- **托盘常驻**：左键唤起，右键菜单（打开 / 立即提示 / 静音 1 小时 / 开机自启 / 退出）；关窗 = 隐藏到托盘
- **毛玻璃**：Win11 原生 `backgroundMaterial: 'acrylic'` + 自绘玻璃层（渐变 / 噪点 / 高光边），跟随系统深浅色

### 快捷键

| 键 | 作用 |
|---|---|
| `←` `→` | 上一周 / 下一周 |
| `T` | 回到本周 |
| `N` | 新建事件 |
| `Ctrl+F` | 搜索 |
| `Esc` | 关闭浮层 |

### 技术栈

Electron 38 · React 19 · TypeScript · Vite 7（electron-vite）
数据层用 Node 内置 `node:sqlite`（零原生编译），重复规则 `rrule`，日期 `date-fns`，IPC 校验 `zod`。
数据落在 `%APPDATA%\work schedule\data.db`，单文件，拷走即备份。

### 已知限制

- 仅 Windows；Win10 没有原生亚克力，会退化为半透明深色玻璃
- 开机自启只在安装版（`app.isPackaged`）生效；本版用便携版分发，首次运行请手动把 exe 建个快捷方式放进启动项，或在「设置」里打开（会在下次启动生效）
- 时区跟随系统，跨时区旅行时历史事件按当前时区渲染
- 未做：ICS 导入导出、周报统计、多显示器位置记忆、拼音搜索

### 快速验证提醒是否正常

1. 解压运行便携版，随便建一个 3 分钟后的日程
2. 按 `Win+L` 锁屏再解锁 → 右下角应弹出提醒卡且不抢焦点
3. 关掉主窗 → 托盘图标仍在，右键可退出
